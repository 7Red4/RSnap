RSnap

Windows 截圖工具：按快速鍵凍結畫面、框選範圍，截圖直接進剪貼簿，還能標註、吸色、存檔。

開始使用 截圖 預覽卡片 編輯視窗 設定 常見問題 從原始碼建置

開始使用

  1. 雙擊 RSnap.exe。會打開設定視窗，同時開始待命。
  2. 按 Ctrl + F1 開始截圖。

關閉設定視窗後 RSnap 仍在系統匣待命。預設會開機自動啟動，開機時不會跳出設定視窗。

RSnap 只會有一個執行中的程式；已在執行時再雙擊 exe，會打開原本那個的設定視窗。

系統匣

  • 左鍵：打開設定。
  • 右鍵：開始截圖、設定、結束 RSnap。

截圖

按下快速鍵後所有螢幕都會凍結，游標變成紅色十字，旁邊跟著 10 倍放大鏡和游標所指像素的色碼。

操作結果
按住左鍵拖曳後放開截取範圍寫入剪貼簿，右上方跳出預覽卡片
只點一下左鍵留在截圖模式
點中鍵複製游標所指顏色（如 #FF0AAB）並離開
點右鍵或 Esc直接離開，拖曳途中也可以
  • 框選時會顯示選取範圍的 寬 × 高，框外變暗。
  • 多螢幕會一起凍結，可以跨螢幕框選；不同縮放比例的螢幕一律以實體像素計算。
  • 剪貼簿同時寫入點陣圖與 PNG 兩種格式，貼到大部分程式都能用。

預覽卡片

截圖後右上方會出現預覽卡片，預設停留 5 秒，不會搶走焦點。

  • 滑鼠移到卡片上時倒數暫停，移開後重新倒數 5 秒。
  • 右上角的 × 立即關閉。
  • 滑鼠移入時出現兩個按鈕：
    • 畫筆：開啟編輯視窗。
    • 下載：存到設定的資料夾，卡片會顯示檔名。

吸色時則會在畫面上方中央顯示「已複製顏色 #RRGGBB」，背景就是那個顏色。

編輯視窗

工具

工具列都是圖示，滑鼠移上去會顯示名稱。

工具用法
選取點物件選取，拖曳移動，拖控制點調整大小；雙擊文字可修改
畫筆自由繪製
方形拖曳畫長方形，按住 Shift 變正方形
圓形拖曳畫正圓
橢圓拖曳畫橢圓
文字點一下開始輸入，支援中文輸入法與多行；Ctrl + Enter、Esc 或點其他地方完成
畫筆等工具一律是「新增」。要選取或移動既有物件，請先切到「選取」工具。

顏色、粗細與實心／空心

  • 預設色：紅、黃、藍、綠、黑，另有自訂顏色和吸管（吸取含標註內容的畫面）。
  • 粗細 1 到 40 px。選文字工具時改為字型、字重、字級選單。
  • 實心／空心切換鈕決定方形、圓形、橢圓的畫法。實心圖形沒有線條，所以選這三個工具時粗細會停用；畫筆不受影響。
  • 工具列上的設定是預設值，新物件都會套用，下次開啟也會記得。

修改既有物件

選取物件後，虛線框旁會出現浮動面板，只修改該物件，不影響預設值：

  • 畫筆線條：顏色、吸管、粗細
  • 圖形：顏色、吸管、實心／空心、粗細（實心時停用）
  • 文字：顏色、吸管、字型、字重、字級

實心圖形點內部就能選取；空心圖形要點在線條上。

快捷鍵

按鍵功能
Ctrl + Z / Ctrl + Y復原 / 重做
Delete刪除選取的物件
Esc取消吸管或取消選取

完成編輯

  • 複製或儲存：視窗關閉並跳出預覽卡片。從卡片再次編輯時，之前畫的物件都還能修改（復原紀錄不保留）。
  • 直接關閉視窗：不會詢問，未複製或儲存的修改會捨棄，並以卡片顯示當下剪貼簿裡的圖片。
  • 圖片比視窗大時會縮小顯示，但輸出一律是原始解析度。

設定

修改後立即生效並自動儲存。

項目預設值說明
儲存路徑「下載」資料夾資料夾不存在會自動建立；無法寫入時會請你重新選擇
儲存格式PNGPNG、JPG（品質 92）、WebP（無損）
截圖快速鍵Ctrl + F1註冊失敗時保留原快速鍵並顯示原因
開機時自動啟動開啟寫入目前使用者的開機項目，不需要系統管理員權限

檔名格式為 Screenshot_20261104_191500.png，同名時自動加上 _1、_2。

設定檔位於 %APPDATA%\RSnap\config.json，編輯器的預設顏色、粗細、字型等也存在這裡。刪除此檔即可還原所有預設值。

常見問題

Office 裡按 Ctrl + F1 不再收合功能區

RSnap 的全域快速鍵優先。想保留 Office 的行為，請到設定換一組快速鍵。

快速鍵沒有反應

可能被其他程式佔用。RSnap 啟動時若註冊失敗會自動打開設定視窗，換一組後按「套用」即可。

影片截出來是黑的

受 DRM 保護的內容無法截取。獨佔全螢幕的遊戲、UAC 確認畫面和登入畫面也可能截不到，這是系統限制。

按 Esc 沒有離開截圖模式

前景是系統管理員權限的視窗時，RSnap 可能拿不到鍵盤焦點。改按右鍵離開即可。

搬動 exe 後開機沒有自動啟動

手動執行一次新位置的 RSnap.exe，開機項目就會更新成新路徑。

怎麼完全移除？

在設定中關閉「開機時自動啟動」，從系統匣結束 RSnap，再刪除 exe 和 %APPDATA%\RSnap 資料夾。

從原始碼建置

需要 Rust（MSVC 工具鏈）以及含 C++ 工具的 Visual Studio Build Tools。

cargo build --release   # 輸出 target\release\RSnap.exe
cargo test              # 單元測試

重新產生圖示：

cargo run --example make_icon -- assets\RSnap.ico

完整行為規格與設計理由請見 docs/SPEC.md。
