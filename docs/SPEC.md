# RSnap 規格書

使用教學請見 [README](../README.md)。本文件記錄行為規格和做這些決定的原因。

## 1. 啟動與常駐

- 雙擊 exe：打開設定視窗，同時開始監聽快速鍵。
- 帶 `--background` 啟動（開機自動啟動使用）：不開設定視窗，只在系統匣待命。若快速鍵註冊失敗，仍會打開設定視窗說明。
- 只允許單一執行個體。已在執行時再雙擊 exe，會打開現有執行個體的設定視窗；帶 `--background` 則安靜結束。
- 關閉設定視窗不會結束程式。結束方式：系統匣右鍵選單，或設定視窗的「結束 RSnap」。
- 系統匣：左鍵開設定；右鍵選單有開始截圖、設定、結束。Explorer 重新啟動後會自動把圖示加回去。

## 2. 設定

修改後立即生效並寫入 `%APPDATA%\RSnap\config.json`。

| 項目 | 預設值 | 說明 |
|---|---|---|
| 儲存路徑 | 使用者的「下載」資料夾 | 資料夾選擇視窗 |
| 儲存格式 | PNG | PNG、JPG（品質 92）、WebP（無損） |
| 截圖快速鍵 | `Ctrl + F1` | 註冊失敗時保留原快速鍵並顯示原因 |
| 開機時自動啟動 | 開啟 | 寫入 `HKCU\...\CurrentVersion\Run`，每次啟動會同步 exe 路徑 |

編輯器的預設值（顏色、粗細、實心／空心、字型、字重、字級）也存在同一個檔案。

## 3. 擷取模式

按快速鍵後凍結所有螢幕，並先關閉現有 toast，避免被截進畫面。擷取中再按快速鍵不動作。

顯示內容：

- 紅色十字游標。
- 放大預覽：放大 10 倍、15×15 格，中心格以紅框標示，下方顯示色塊和 `#RRGGBB`。預設在游標右下方，超出該螢幕時翻到另一側。
- 選取中：框外變暗、紅色框線，並顯示 `寬 × 高`。

操作：

| 操作 | 結果 |
|---|---|
| 左鍵拖曳後放開 | 選取範圍寫入剪貼簿，並顯示卡片 toast |
| 左鍵點擊（寬或高小於 3 像素） | 留在擷取模式 |
| 中鍵 | 複製 `#RRGGBB` 文字，離開，顯示顏色 toast |
| 右鍵或 `Esc` | 直接離開，包含拖曳途中 |

中鍵和右鍵都在**放開**時才動作。若在按下時就關閉擷取畫面，放開的動作會落到底下的程式，右鍵就會叫出它的右鍵選單。

雙螢幕時可以跨螢幕框選。不同縮放比例的螢幕以實體像素計算，介面大小跟隨游標所在螢幕。

剪貼簿同時寫入 `CF_DIB` 和 `PNG` 兩種格式，以兼顧相容性。

## 4. Toast

同時只存在一個。兩種樣式都不會搶走焦點。

### 卡片 toast

- 位置：滑鼠所在螢幕的右上方。
- 內容：截圖預覽和狀態文字（已複製到剪貼簿、已儲存 檔名）。
- 預設停留 5 秒。滑鼠移入時停止倒數，移出後重新倒數完整的 5 秒。
- 右上角固定有關閉（×）按鈕，點擊立即關閉 toast。
- 滑鼠移入時，編輯和儲存的純圖示按鈕在預覽中央左右並排。
- 編輯：關閉 toast，開啟編輯視窗。
- 儲存：存到設定的路徑並更新狀態文字。路徑失效時會要求重新選擇資料夾。

### 訊息 toast

- 位置：滑鼠所在螢幕的中間上方，停留 2.5 秒，滑鼠可穿透。
- 吸色時顯示 `已複製顏色 #RRGGBB`，背景為該顏色，文字依亮度自動選黑或白。
- 也用於顯示錯誤訊息。

## 5. 編輯視窗

### 工具列

- 除了「複製」「儲存」是圖示加文字，其他工具都是純圖示，滑鼠移上去會顯示名稱。
- 工具：選取、畫筆、方形、圓形、橢圓、文字。選中畫筆時，畫布上的游標會變成畫筆，落筆點在筆尖。
- 預設色：紅、黃、藍、綠、黑，另有自訂顏色和吸管。
- 粗細：1 到 40 px。使用文字工具時，粗細改為字型、字重、字級選單。
- 實心／空心切換鈕：決定新的方形、圓形、橢圓是實心或空心，開啟時按鈕反白，三個圖形工具的圖示也改成實心。預設空心。
- 實心模式下選取圖形工具時，粗細停用，因為實心圖形沒有線條。畫筆仍使用粗細，所以選畫筆或選取工具時不停用。

### 建立物件

新物件使用工具列的預設值。畫筆等工具一律是新增內容；要選取物件必須切換到「選取」工具，避免「點到舊線條時到底是選取還是繼續畫」的衝突。

- 方形可拉成長方形，按住 `Shift` 變正方形；圓形固定等比例。圖形依切換鈕畫成實心或空心。
- 圖形工具只點一下不會建立物件；畫筆點一下會留下一個點。
- 文字：點擊後輸入，支援中文輸入法和多行。`Ctrl + Enter`、`Esc` 或點其他地方完成；內容為空時不建立物件。

### 編輯物件

- 選取時顯示虛線框。線條和圖形有 8 個控制點可調整大小，文字以字級調整。
- 浮動面板位於虛線框上方，空間不夠時改放下方，避免蓋住物件。
- 畫筆線條的面板：選色、吸管、粗細。
- 圖形的面板：選色、吸管、實心／空心、粗細。實心時粗細停用，切回空心會恢復原本的粗細。
- 文字的面板：選色、吸管、字型、字重、字級。
- 實心圖形點內部也能選取；空心圖形要點線條。
- 拖曳可移動，`Delete` 刪除，雙擊文字可修改內容。

### 預設值的記憶規則

- 工具列的選色、吸管、粗細、實心／空心、字型設定會更新預設值，下次開啟會記得。
- 修改既有物件不會影響預設值。

### 其他

- 吸管吸取含繪圖內容的畫面。
- 復原和重做：`Ctrl + Z`、`Ctrl + Y`。
- 快速連點時，只有「選取工具雙擊文字」算雙擊；其他情況每一下都視為一般點擊，連點按鈕才不會少算。
- 圖片比視窗大時會縮小顯示，輸出一律是原始解析度。

### 完成

- 複製：寫入剪貼簿，關閉視窗，跳卡片 toast。
- 儲存：存到設定的路徑，關閉視窗，跳卡片 toast。
- 從 toast 再次編輯時，物件都還能修改。復原紀錄不會保留。
- 直接關閉視窗：不詢問，未複製或儲存的修改會捨棄，並跳卡片 toast 顯示當下剪貼簿裡的圖片。若圖片是 RSnap 複製的，再按編輯時物件還能修改；若剪貼簿沒有圖片，改顯示訊息 toast。

## 6. 存檔

- 檔名：`Screenshot_YYYYMMDD_HHMMSS.副檔名`，同名時加上 `_1`、`_2`。
- 資料夾不存在時會自動建立；仍無法寫入時要求重新選擇，成功後更新設定。

## 7. 已知限制

- 受 DRM 保護的影片可能是黑畫面。
- 獨佔全螢幕的遊戲可能截不到。
- UAC 確認畫面和登入畫面無法截取。
- 系統管理員權限的視窗在前景時，RSnap 可能無法取得鍵盤焦點，`Esc` 可能失效，此時請用右鍵離開。
- `Ctrl + F1` 在 Office 中原本用來收合功能區，RSnap 執行時會改成截圖。

## 8. 技術架構

- Rust，直接使用 Win32 API（`windows` crate），不依賴 UI 框架。
- 繪圖：Direct2D；文字：DirectWrite。匯出時用同一份繪圖程式畫到 WIC 點陣圖，確保輸出和畫面一致。
- 文字輸入和字型選單使用原生控制項，才能支援中文輸入法和系統字型清單。
- 編碼：`image` crate。

| 模組 | 職責 |
|---|---|
| `main.rs` | 程式進入點、單一執行個體、系統匣、訊息迴圈 |
| `overlay.rs` | 擷取模式 |
| `toast.rs` | 兩種 toast |
| `editor.rs` | 編輯視窗 |
| `settings.rs` | 設定視窗 |
| `actions.rs` | 複製、儲存等共用流程 |
| `model.rs` | 標註物件、幾何、復原紀錄（可單元測試） |
| `imaging.rs` | 擷取、編碼、存檔、剪貼簿 |
| `gfx.rs` | Direct2D 和 DirectWrite 輔助函式、工具列圖示 |
| `config.rs`、`hotkey.rs`、`autostart.rs` | 設定、快速鍵、開機啟動 |
