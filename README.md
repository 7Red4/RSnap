# RSnap

Windows 截圖工具。按一下快速鍵凍結畫面、框選範圍，截圖就進剪貼簿，還能直接標註、吸色和存檔。

完整規格請見 [docs/SPEC.md](docs/SPEC.md)。

## 開始使用

1. 雙擊 `RSnap.exe`，會打開設定視窗，同時開始待命。
2. 按 `Ctrl + F1` 開始截圖。

關閉設定視窗後，RSnap 仍會在系統匣待命。預設會開機自動啟動，開機時不會跳出設定視窗。

## 截圖

按下快速鍵後，整個畫面會凍結，游標變成紅色十字，右下方跟著放大預覽和游標所指像素的色碼。

| 操作 | 結果 |
|---|---|
| 按住左鍵拖曳後放開 | 截取選取範圍，寫入剪貼簿，右上方跳出預覽卡片 |
| 點一下左鍵，沒有拖曳 | 留在截圖模式 |
| 點中鍵 | 複製游標所指顏色的色碼（如 `#FF0AAB`）並離開 |
| 點右鍵或按 `Esc` | 直接離開，不做任何事 |

多螢幕會一起凍結，也可以跨螢幕框選。

## 預覽卡片

卡片預設停留 5 秒，右上角的 × 可以立刻關閉。滑鼠移到卡片上時倒數會暫停，並顯示兩個圖示按鈕；移開後重新倒數 5 秒。

- **畫筆圖示**：開啟編輯視窗。
- **下載圖示**：存到設定的資料夾。

## 編輯視窗

工具列上的工具都是圖示，滑鼠移上去會顯示名稱。

| 工具 | 用法 |
|---|---|
| 選取 | 點物件選取，可拖曳移動或拖曳控制點調整大小；雙擊文字可修改內容 |
| 畫筆 | 自由繪製 |
| 方形 | 拖曳畫出長方形，按住 `Shift` 變正方形 |
| 圓形 | 拖曳畫出正圓 |
| 橢圓 | 拖曳畫出橢圓 |
| 文字 | 點一下開始輸入，`Ctrl + Enter`、`Esc` 或點其他地方完成 |

工具列上的**實心／空心切換鈕**決定方形、圓形、橢圓畫出來是實心或空心，這三個工具的圖示也會跟著改變。實心圖形沒有線條，所以選這些工具時粗細會停用；畫筆不受影響。

工具列上的顏色和粗細是**預設值**，新物件都會套用，下次開啟也會記得。實心／空心、字型、字重、字級也一樣。

選取物件後，虛線框旁的浮動面板只會修改該物件，不會影響預設值：

- 畫筆線條：顏色、吸管、粗細
- 圖形：顏色、吸管、實心／空心、粗細（實心時停用）
- 文字：顏色、吸管、字型、字重、字級

| 快捷鍵 | 功能 |
|---|---|
| `Ctrl + Z` / `Ctrl + Y` | 復原 / 重做 |
| `Delete` | 刪除選取的物件 |
| `Esc` | 取消吸管或取消選取 |

完成後按**複製**或**儲存**，編輯視窗會關閉並跳出預覽卡片。從卡片再次開啟編輯時，之前畫的物件都還能修改。

直接關閉編輯視窗不會詢問，未複製或儲存的修改會捨棄，並跳出卡片顯示當下剪貼簿裡的圖片。

## 設定

在系統匣圖示上點左鍵，或再次雙擊 `RSnap.exe`，都能打開設定。右鍵選單可以開始截圖或結束程式。

| 項目 | 預設值 |
|---|---|
| 儲存路徑 | 使用者的「下載」資料夾 |
| 儲存格式 | PNG（可選 JPG、WebP） |
| 截圖快速鍵 | `Ctrl + F1` |
| 開機時自動啟動 | 開啟 |

存檔名稱為 `Screenshot_20261104_191500.png`，同名時會自動加上序號。

設定檔位於 `%APPDATA%\RSnap\config.json`。

## 常見問題

**Office 裡按 `Ctrl + F1` 不再收合功能區。** RSnap 的全域快速鍵優先，想保留 Office 的行為請到設定換一組。

**快速鍵沒有反應。** 可能已被其他程式佔用。RSnap 啟動時若註冊失敗會自動打開設定視窗，換一組後按「套用」即可。

**影片截出來是黑的。** 受 DRM 保護的內容無法截取。獨佔全螢幕的遊戲、UAC 確認畫面和登入畫面也可能截不到，這些都是系統限制。

**搬動 exe 後開機沒有自動啟動。** 手動執行一次新位置的 `RSnap.exe`，開機項目就會更新。

## 從原始碼建置

需要 Rust（MSVC 工具鏈）和含 C++ 工具的 Visual Studio Build Tools。

```powershell
cargo build --release   # 輸出到 target\release\RSnap.exe
cargo test              # 單元測試
```

重新產生圖示：

```powershell
cargo run --example make_icon -- assets\RSnap.ico
```
